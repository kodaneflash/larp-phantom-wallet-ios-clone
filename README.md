# Larp Phantom Wallet iOS App Clone — Solana Wallet UI Demo

An **unofficial Phantom-style crypto wallet simulation for iPhone** by Larp Apps. The interface brings together a portfolio home, token cards, wallet-position views, and adjustable display values for fictional demos. A number shown in the app is not proof that a wallet owns that amount of crypto.

## Phantom-style wallet experience

- Portfolio home with token cards, quick actions, and wallet navigation.
- Configurable crypto holdings and cash display values reflected on the home screen.
- A tracked Solana wallet-position view, as described on the product page.
- Additional market and token content that supports a connected walkthrough.

For previews, latest features, and availability, see the [Phantom-style wallet page](https://larpapps.com/phantom). This repository is a **product overview**, not wallet source code or an official Phantom distribution.
